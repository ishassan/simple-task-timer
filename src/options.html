Simple Task Timer

Shortcut

Open Simple Task Timer

This shortcut works in any Firefox window. Click the box, then press the new shortcut. Press Escape to cancel.

Keys in the popup

These keys act on the task that has the focus. In the name field, press the Down arrow to go to the list.

Keys that do not change: Up and Down arrows move between tasks, Enter edits, Escape goes back to the name field, and Ctrl+Z undoes. In the empty name field, Space pauses or resumes the last task.
